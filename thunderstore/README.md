# Hufsa

*Something cold walks the forests at night.*

It doesn't attack your base. It doesn't drop loot. It can't be fought.
It only watches, from far away, between the trees.

Look at it long enough, and one night it stops watching.

## What you need to know

- It comes at night. In the far north, not only at night.
- You can't kill it. Don't waste your arrows.
- If you hear breathing behind you, turn around.
- If it speaks, run.
- A roof and four walls are worth more than any weapon.

## Installation

Install with **r2modman** or **Thunderstore Mod Manager**. BepInEx and Jotunn are installed for you.

**Multiplayer:** the server and every player need the mod, on the same version.

**Config:** `BepInEx/config/benjinamin.hufsa.cfg`. Gameplay settings come from the server, sound and visual settings are per player.
